# Template de Prompt para Criar uma Rota de API

Crie a rota `GET /workout-plans/:id/days/:dayId`

## Descrição

Essa rota deve retornar o dia de treino recebido, seus exercícios e, para cada exercício, suas sessões (workout sessions).

## Requisitos Técnicos

N/A

## Autenticação

- Rota protegida.
- O usuário precisa ser dono do plano de treino recebido.

## Request

```ts
interface Body {}
```

```ts
interface Params {
  id: string; // ID do plano de treino
  dayId: string; // ID do dia de treino
}
```

```ts
interface Query {}
```

## Response

```ts
interface StatusCode200 {
  id: string;
  name: string;
  isRest: boolean;
  coverImageUrl?: string;
  estimatedDurationInSeconds: number;
  weekDay: string;
  exercises: Array<{
    // tudo que está no model WorkoutExercise, com exceção de createdAt e updatedAt
    id: string;
    name: string;
    sets: number;
    reps: number;
    order: number;
    restTimeInSeconds: number;
  }>;
  sessions: Array<{
    id: string;
    workoutDayId: string;
    startedAt?: string; // YYYY-MM-DD
    completedAt?: string; // YYYY-MM-DD
  }>;
}
```
