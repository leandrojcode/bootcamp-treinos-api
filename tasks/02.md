# Template de Prompt para Criar uma Rota de API

Crie a rota `PATCH /workout-plans/{id(uuid)}/days/{id(uuid)}/sessions/:id(uuid)}`

## Descrição

Ela atualiza o status de uma sessão de treino para concluída.

## Requisitos Técnicos

- Use case deve se chamar "CompleteWorkoutSession".

## Autenticação

- Rota protegida.

## Request

```ts
interface Params {
  id: string; // ID do plano de treino
  dayId: string; // ID do dia de treino
  sessionId: string; // ID da sessão de treino (:id)
}
```

```ts
interface Body {
  completedAt: string; // ISO String (2026-02-25T19:46:55.754Z)
}
```

## Response

```ts
interface StatusCode200 {
  id: string;
  completedAt: string; // ISO STRING DATE (2026-02-25T19:46:55.754Z)
  startedAt: string; // ISO STRING DATE (2026-02-25T19:46:55.754Z)
}
```
