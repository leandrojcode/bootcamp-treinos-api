# Template de Prompt para Criar uma Rota de API - Passo 07

Crie a rota `GET /workout-plans` com Query Params.

## Descrição

Essa rota deve listar os planos de treino do usuário autenticado. Ela aceita um filtro opcional no query param chamado "active". Caso esteja presente, filtra pelo status do plano. Se não estiver presente, traz todos os planos (ativos e inativos). Para cada dia de treino retornado, inclua todos os dados, inclusive os exercícios.

## Requisitos Técnicos

- Use case deve se chamar "GetWorkoutPlans".

## Autenticação

- Rota protegida via `better-auth`.

## Documentação (Scalar)

- **Tags:** `["Workout Plan"]`
- **Summary:** `"Get all workout plans with details"`

## Request

```ts
interface Query {
  active?: string; // "true" ou "false" (opcional)
}
```

## Response

```ts
interface StatusCode200 {
  workoutPlans: Array<{
    id: string;
    name: string;
    isActive: boolean;
    workoutDays: Array<{
      id: string;
      name: string;
      weekDay: string;
      isRest: boolean;
      coverImageUrl?: string;
      estimatedDurationSeconds: number;
      exercises: Array<{
        id: string;
        name: string;
        sets: number;
        reps: number;
        order: number;
        restTimeInSeconds: number;
      }>;
    }>;
  }>;
}
```
